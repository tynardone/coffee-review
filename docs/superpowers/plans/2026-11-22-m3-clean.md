# M3 Clean Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `coffee-review clean` turns the parsed text tables into typed clean (silver) Parquet tables for roasted and green reviews, plus a cleaning log of every change, a report, and a schema contract checked on every run.

**Architecture:**
- **Pure transforms** (`transforms/`): one module per field family, each a `LazyFrame → LazyFrame` function that reads `raw_<field>` columns and writes typed columns plus a rule column. Procedural parsing (places, price) is a pure Python function applied to each *distinct* raw value, then joined back.
- **Hand-kept lookup tables** (`transforms/lookups/*.csv`) for places, currencies and units, read with `importlib.resources`.
- **A contract** (`models/clean.py`): pandera `DataFrameModel`s with the Polars backend, plus the fixed list of rule names.
- **A storage boundary:** `CleanStore` Protocol, Parquet store, in-memory fake, one contract test. The parsed store gains `read_table`.
- **A pipeline** (`pipeline/clean.py`) that runs the transforms in order, extracts the log, checks that no value vanished unlogged, validates, reports and writes. A CLI command on top.

**Tech Stack:** Python 3.14, Polars, pandera (Polars backend), pydantic, Typer, pytest, hypothesis, inline-snapshot.

**Spec:** `docs/superpowers/specs/2026-11-22-m3-clean-design.md` (approved). Background: ADR 0007, `docs/agtron.md`, `docs/interpreting_reviews.md`.

## Global Constraints

- **Each task ends with a pause for Tyler's review.** Claude explains the change and commits only after Tyler has reviewed it. One concern per commit.
- **The dependency rule:** `cli → pipeline → {storage, transforms} → {models, config}`. `transforms/` does no I/O except reading its own lookup CSVs through `importlib.resources`. Only `storage/` knows data paths and formats.
- **M3 reads only the parsed store.** No HTML, no raw layer, no network.
- **Every non-null parsed value that becomes null has a cleaning-log row naming the rule.** Every change (swap, correction, inference, removal) has one too.
- **Corrections and doubts are flagged, never hidden:** `agtron_swapped`, `agtron_corrected`, `agtron_suspect`, `price_currency_inferred`.
- **Origin:** Hawaiʻi and Puerto Rico are their own countries; more than one country, or a broad area or blend, is `"Multiple"`. **Roaster location:** Hawaiʻi is a US state.
- **Agtron swap window:** review months June 2002 to March 2003 inclusive, per row (ground < whole → swap; otherwise in window → suspect).
- **Currency:** bare `$` is USD, except for roasters in Canada, Australia, Hong Kong, Singapore, New Zealand (that country's dollar, flagged inferred); `¥` is JPY for Japan, CNY for China (flagged inferred), otherwise null `ambiguous_currency`.
- **`review_month`** is a `Date` that is always the 1st.
- **Tests never touch the network or `data/`.**
- **Every task ends with `uv run pre-commit run --all-files` (exit 0) and `uv run pytest` passing.**

## Review Focus

1. **Markers in odd case and spacing** (` NA `, `Na`, `n/a`, `NR`, `Not Disclosed.`): they must be recognised, not left as unparsed. Tests: `test_unknown_markers_any_case` (Task 4), `test_not_disclosed_variants` (Task 6).
2. **Curly and straight apostrophes and quotes in place names** (`Hawai’i`, `Hawai'i`, `“Big Island” of Hawai’i`, `"Big Island" of Hawaii`): all must reach `Hawaii`. Test: `test_hawaii_spellings_all_place` (Task 6).
3. **Amounts with thousands separators or spaces** (`¥ 2,420/200 grams`, `$35,000 LAK/250 grams`): the amount must be 2420 and 35000, not 2 or null. Test: `test_amount_separators` (Task 7).
4. **The Agtron window's edges:** June 2002 and March 2003 are in it; May 2002 and April 2003 are not. Test: `test_swap_window_edges` (Task 5).
5. **An empty dataset** (a parsed green table with zero rows): clean must still write an empty table that passes the contract. Test: `test_empty_dataset_cleans` (Task 10).

## Shared names (used by every task)

- **Raw columns:** the pipeline renames each parsed field it cleans to `raw_<field>` (e.g. `raw_agtron`), so a clean column can reuse the field's name (`rating`) and the log can quote the original.
- **Rule columns:** `_rule_<field>`, type `pl.List(pl.String)`, holding the rules applied to that field in that row (empty list when none).
- **A transform:** `def clean_x(frame: pl.LazyFrame, ...) -> pl.LazyFrame`, adding output columns and its rule columns, leaving every other column alone.
