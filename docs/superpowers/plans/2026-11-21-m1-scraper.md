# M1 Scraper Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `coffee-review scrape [--full] [--limit N]` downloads every coffeereview.com review as raw HTML, fetching only new or changed reviews on reruns. It stops cleanly on any pushback and keeps a manifest that the rest of the code reaches only through a storage Protocol.

**Architecture:** The pure pieces (models, sitemap parser, fetch rules) are built and tested first. Then come the storage boundary (a `RawStore` Protocol, the gzip+SQLite implementation and an in-memory fake, all checked by one shared contract test), and the client's response classification. The pipeline joins them through injected dependencies, and the CLI only maps the summary to output and exit codes.

**Tech Stack:** Python 3.14, httpx, pydantic, stdlib `sqlite3`, `gzip`, `xml.etree.ElementTree`, Typer, pytest + pytest-asyncio. No new runtime dependencies.

**Spec:** `docs/superpowers/specs/2026-11-21-m1-scraper-design.md` (parent: `docs/superpowers/specs/2026-11-20-pipeline-roadmap-design.md`).

## Global Constraints

- **Each task ends with a pause for Tyler's review.** Claude explains what changed, why it's built that way, and what to look at closely, and commits only after Tyler's review and questions. One concern per commit.
- Dependency rule: `cli → pipeline → {clients, storage, parsers} → {models, config}`. `parsers/` and `pipeline/fetch_rules.py` import no I/O.
- **Only `storage/` knows data formats and paths.** Everything else holds a `RawStore`.
- No new runtime dependencies.
- All datetimes are timezone-aware UTC. Time is passed in as `now`, and nothing reads the clock except `cli.py`.
- Tests never touch the network, except one test marked `@pytest.mark.network`.
- Pushback means a 429, a 403, a challenge page, or 5 temporary failures in a row. A plain 503 is a temporary failure. A `gone` page never counts toward the run.
- Exit codes: 0 finished (even if some pages failed), 1 error, 2 stopped by pushback.
- Delisting guard: if a run would mark more than 5% of the manifest delisted, it marks nothing and exits 1.
- Every task ends with `uv run pre-commit run --all-files` and `uv run pytest` passing.

## Review Focus

1. **A slug that's unsafe as a filename** (`..`, `a/b`, empty). It must be rejected before it reaches the filesystem. Test: `test_slug_rejects_path_tricks` (Task 1).
2. **The same slug in two sitemaps.** One entry is kept, the one with the newest lastmod; it must not be fetched twice or flip-flop. Test: `test_duplicate_slugs_keep_newest_lastmod` (Task 2).
3. **A crash in the middle of a write.** The previous page and manifest row must be left intact, with no temp files behind. Test: `test_failed_write_leaves_previous_page_and_no_temp_files` (Task 4).
4. **A manifest written by a future schema version.** Opening it must fail with a clear error, not silently misread. Test: `test_unknown_schema_version_raises` (Task 4).
5. **A sitemap index with no review sitemaps.** The run must stop as an error, not treat every review as delisted. Test: `test_index_without_review_sitemaps_is_error` (Task 6).

### Task 3: Fetch rules

The most important tests in M1. Pure: imports only `models`.

**Files:**
- Create: `src/coffee_review/pipeline/__init__.py` (empty), `src/coffee_review/pipeline/fetch_rules.py`
- Test: `tests/pipeline/test_fetch_rules.py`

**Interfaces:**
- Consumes: `SitemapEntry`, `ManifestRecord`, `FetchReason`.
- Produces:
  - `LOOKBACK = timedelta(hours=24)`; `DELISTING_LIMIT = 0.05`.
  - `select_reviews_to_fetch(entries: Sequence[SitemapEntry], manifest: Mapping[str, ManifestRecord], *, now: datetime, full: bool) -> list[tuple[SitemapEntry, FetchReason]]`. The result is ordered newest lastmod first, with `None` last and ties broken by slug.
  - `class Delistings(NamedTuple)`: `delisted: frozenset[str]`, `relisted: frozenset[str]`.
  - `find_delistings(entries: Sequence[SitemapEntry], manifest: Mapping[str, ManifestRecord]) -> Delistings`.
  - `delisting_exceeds_limit(plan: Delistings, manifest_size: int) -> bool`.
- Rules, applied in this order (the first match is the reason; no match means unchanged):
  1. `full` → `FULL`
  2. not in the manifest → `NEW`
  3. `status == "failed"` → `FAILED`
  4. `status == "gone"`: `CHANGED` if `lastmod` is set and later than `last_attempt_at`; otherwise skip
  5. `fetched_at is None` → `UNKNOWN_TIME`
  6. `lastmod` is set and later than `fetched_at` → `CHANGED`
  7. `lastmod` is set, `fetched_at - LOOKBACK <= lastmod <= fetched_at`, `not lookback_done`, and `now >= fetched_at + LOOKBACK` → `LOOKBACK`

### Task 4: Storage boundary

**Files:**
- Create: `src/coffee_review/storage/raw_store.py`, `tests/fakes.py`
- Delete: `src/coffee_review/storage/review_store.py` (a placeholder, replaced by this task)

**Interfaces:**
- Consumes: `SitemapEntry`, `ManifestRecord`.
- Produces, in `storage/raw_store.py`:
  - `class RawStore(Protocol)`:
    - `load_manifest() -> dict[str, ManifestRecord]`
    - `save_page(entry: SitemapEntry, html: str, fetched_at: datetime, *, lookback: bool) -> None`
    - `record_failure(entry: SitemapEntry, error: str, attempted_at: datetime) -> None`
    - `record_gone(entry: SitemapEntry, reason: str, attempted_at: datetime) -> None`
    - `mark_delisted(slugs: Collection[str], at: datetime) -> None`
    - `mark_relisted(slugs: Collection[str]) -> None`
    - `read_page(slug: str) -> str`, which raises `PageNotFoundError`
    - `close() -> None`
  - `class PageNotFoundError(KeyError)`; `class ManifestSchemaError(Exception)`.
  - `class GzipSqliteRawStore`, constructed as `GzipSqliteRawStore(root: Path)`:
    - Pages go in `root/reviews/<slug>.html.gz`. They're written to a `NamedTemporaryFile` in that folder, then moved into place with `os.replace`. On error the temp file is removed.
    - The manifest is `root/manifest.sqlite` with `journal_mode=WAL` and `PRAGMA user_version = 1`. Opening a database with any other non-zero version raises `ManifestSchemaError`.
    - The table is `reviews`, with columns as in `ManifestRecord`. Datetimes are stored as ISO text and the bool as 0/1.
  - `open_raw_store(settings: Settings) -> RawStore` returns `GzipSqliteRawStore(settings.data_dir / "raw")`.
- Semantics (pinned by the contract tests):
  - **`save_page`:** sets `status="ok"`, `last_error=None`, `fetched_at=last_attempt_at=fetched_at`, `lookback_done=lookback`, `url` and `lastmod` from the entry. `first_seen_at` is set only when the row is first inserted.
  - **`record_failure` / `record_gone`:** set `status` and `last_error`, and set `last_attempt_at` to the attempt time. They keep `fetched_at` and the saved page. On a first insert, `fetched_at=None`.
  - **`mark_relisted`:** sets `delisted_at=None`.
- `tests/fakes.py` holds `InMemoryRawStore`, which implements `RawStore` with dicts.

### Task 6: Scrape pipeline

**Files:**
- Create: `src/coffee_review/pipeline/scrape.py`
- Modify: `tests/fakes.py` (add `FakeSite`)
- Test: `tests/pipeline/test_scrape.py`

**Interfaces:**
- Consumes: everything from Tasks 1–5.
- Produces:
  - `MAX_CONSECUTIVE_FAILURES = 5`
  - `async def run_scrape(settings: Settings, *, client: CoffeeScraper, store: RawStore, full: bool, limit: int | None, now: datetime) -> ScrapeSummary`
  - `def scrape(settings: Settings, *, full: bool, limit: int | None, now: datetime) -> ScrapeSummary`. This is the composition root: it opens `CoffeeScraper(settings.coffee_site)` and `open_raw_store(settings)`, calls `asyncio.run(run_scrape(...))`, and closes both.
  - `FakeSite`, in `tests/fakes.py`, is built from `{path: httpx.Response | Callable[[], httpx.Response]}`. It exposes `.transport` (a `MockTransport`) and `.requested: list[str]` (the paths requested).
- `run_scrape` flow:
  1. **Sitemaps:**
     - Fetch the index. If it's `Pushback`, return `outcome="stopped"`; if `Failed` or `Gone`, return `outcome="error"`.
     - Parse the index. No review sitemaps → `outcome="error"`.
     - Fetch and parse every child sitemap with the same handling, then call `dedupe_entries`.
     - A `SitemapParseError` → `outcome="error"`.
  2. **Delistings:**
     - Call `load_manifest()`, then `find_delistings`.
     - If `delisting_exceeds_limit`, return `outcome="error"` with `stopped_reason` naming the count.
     - Otherwise call `mark_delisted` and `mark_relisted`, using `now`.
  3. **Selection:** call `select_reviews_to_fetch`, then apply `limit` by slicing.
  4. **Fetching:** run `settings.coffee_site.max_concurrency` workers that pull from a shared queue. The workers stop taking new items once a stop is set.

     | Result | What happens |
     |---|---|
     | `Fetched` | `save_page(..., lookback=reason is LOOKBACK)`; the consecutive-failure count resets |
     | `Failed` | `record_failure`; the count goes up by 1, and reaching 5 sets a stop |
     | `Gone` | `record_gone`; the count doesn't change |
     | `Pushback` | sets a stop with `f"{reason} at {url}"`; nothing is recorded |

  5. **Summary:**
     - `remaining` is the number of planned items never attempted.
     - `unchanged` is the number of entries minus the number planned.
     - `outcome` is `"stopped"` if a stop was set, otherwise `"finished"`.
     - The summary's `describe()` line is logged at INFO. Each fetch is logged at DEBUG with its reason. Each `Failed`, `Gone` or `Pushback` is logged at WARNING.
